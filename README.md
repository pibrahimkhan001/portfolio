## 🚀 Deploy to GitHub Pages

1. Create a GitHub repository — name it `pibrahimkhan001.github.io` for the cleanest URL
2. Upload all three files: `index.html`, `Global_Resume.pdf`, `README.md`
3. Go to **Settings → Pages → Source → Deploy from branch → main → / (root)** → Save
4. Your site goes live at `https://pibrahimkhan001.github.io` within ~1 minute
